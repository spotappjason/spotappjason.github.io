  • Install
    1. Open the installer. Continue, Install. Spot lands in Applications.
    2. If macOS says it can't check the developer: System Settings → Privacy & Security → Open Anyway, then open Spot again. Older macOS: right-click → Open.

    4. Hover the notch.
